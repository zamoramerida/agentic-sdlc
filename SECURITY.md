# Security policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner through a private channel listed on their GitHub profile. Include affected versions or commits, impact, and safe reproduction details; do not include real user data or active secrets.

Please allow maintainers time to investigate and coordinate a fix before public disclosure. Do not access, modify, or retain data that is not yours while investigating.

## Scope

This repository contains process guidance and templates. Report vulnerabilities in this repository or security issues caused by adopting its recommendations. For a consuming project's vulnerability, use that project's own security reporting channel.

## Response

The maintainer will acknowledge reports when practical, assess severity and impact, and coordinate remediation and disclosure with the reporter. This project currently makes no response-time or support guarantee.
